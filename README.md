# Automated Certificate Generation Agent

An automated tool to generate personalized PDF certificates from an Excel data source and a PDF template. The complete source code and documentation can be found in the [certificate_agent/](certificate_agent/) directory.

## System Output

The agent automatically processes the input data, precisely maps the text over the original template, and generates valid PDF files along with a generation report.
